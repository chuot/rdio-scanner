Rdio Scanner

Administrator Guide

Version 8.0.0. This guide covers the Rdio Scanner server and its administration interface: installing it, meeting its requirements, configuring every feature it offers, driving its APIs, and operating it day to day. The listener web app and the native mobile applications are not covered here; the web app guide documents the listener web app.
