# Rdio Scanner

![Rdio Scanner](./docs/images/rdio-scanner.png?raw=true)

## What is it ?

[Rdio Scanner](https://github.com/chuot/rdio-scanner) is an open source software that ingest and distribute
audio files generated by various software-defined radio recorders. Its interface tries to reproduce the user
experience of a real police scanner, while adding its own touch.

You can listen on any modern browsers using the integrated scanner webapp.

> **How the name is said**
>
> **Rdio Scanner** — /ˈreɪ.di.oʊ ˈskæn.ər/ — *RAY-dee-oh SCAN-er*
>
> The written form *Rdio* is what the screen and this readme show. Say the name out loud as *Raydio*
> when you ask an operator about a call, and they will know at once which product you mean.

## Recorders compatibility

The scanner works with any radio recorder, as long as they can create audio files separated by
conversations or transmissions. Here is a list of recorders known to work:

| Recorder                                                       | API | Dirwatch |
| -------------------------------------------------------------- | --- | -------- |
| [Trunk Recorder](https://github.com/robotastic/trunk-recorder) | X   | X        |
| [RTLSDR-Airband](https://github.com/szpajder/RTLSDR-Airband)   |     | X        |
| [SDRTrunk](https://github.com/DSheirer/sdrtrunk)               | X   |          |
| [voxcall](https://github.com/aaknitt/voxcall)                  | X   |          |
| [ProScan](https://www.proscan.org/)                            |     | X        |
| [DSDPlus Fast Lane](https://www.dsdplus.com/)                  |     | X        |

## Quick start

Always download the latest version of Rdio Scanner from its official repository.

1. Download the latest precompiled version from the [releases page](https://github.com/chuot/rdio-scanner/releases).
   Each release carries one archive per system, named
   `rdio-scanner-<operating system>-<architecture>-v<version>.zip`:

   | Operating system | Architectures                       |
   | ---------------- | ----------------------------------- |
   | FreeBSD          | amd64                               |
   | Linux            | 386, amd64, arm, arm64              |
   | macOS            | amd64, arm64                        |
   | Windows          | amd64                               |

   The [release history](./CHANGELOG.md) tells you what changed in each version, and if you prefer to build
   it yourself, the [build instructions](./COMPILING.md) show you how.

2. Extract the contents of the archive somewhere on your computer.
3. Run the Rdio Scanner executable.
4. Access the administrative dashboard to finalize the configuration.

More detailed instructions are in the documentation: the [administrator guide](./docs/admin-guide.html),
one self-contained HTML file that covers installation, configuration, operation, and troubleshooting on
every system, and the [scanner webapp guide](./docs/user-guide.html),
a file of the same kind for whoever hears calls on the listening screen. The precompiled archives carry both
guides, each with its pictures inside the file it is, so the same instructions are in the folder you
extracted.

## Docker

As a courtesy to Docker users, the scanner is also distributed as a Docker image where a new version is
generated with each new release, on [Docker Hub](https://hub.docker.com/r/chuot/rdio-scanner).
